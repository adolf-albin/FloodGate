# 🛡️ FloodGate

FloodGate is a local defensive cybersecurity learning lab focused on Denial-of-Service concepts, HTTP traffic analysis, monitoring, incident investigation, and rate limiting.

## Learning Path

1. DoS Fundamentals
2. Reconnaissance
3. Traffic Analysis
4. Detection
5. Rate Limiting
6. Incident Investigation
7. Final Challenge

## Safety

FloodGate is designed for controlled localhost use only.

The included traffic simulation is intentionally limited and should not be modified for targeting external systems.
