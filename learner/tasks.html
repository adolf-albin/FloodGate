🛡️ FloodGate Challenges

Task 1

Learn the fundamentals of Denial-of-Service attacks, service availability, legitimate traffic, and excessive requests.

Task 2

Explore the FloodGate service and learn about HTTP endpoints, ports, responses, and service information.

Task 3

Analyze controlled traffic and understand allowed requests, blocked requests, traffic percentages, and response patterns.

Task 4

Learn how security teams detect unusual traffic patterns using logs, source addresses, and HTTP responses.

Task 5

Understand rate limiting and how it helps control excessive requests and protect service availability.

Task 6

Investigate security events using traffic statistics and logs to understand what happened during the simulation.

Task 7

Apply the skills learned throughout FloodGate to complete a practical final security investigation.
