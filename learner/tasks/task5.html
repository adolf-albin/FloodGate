🚦 Task 5 — Rate Limiting

Learning Objectives

Rate limiting is a defensive mechanism that controls how many requests a client can make within a defined period. In this task, investigate the actual threshold and window used by FloodGate and understand what happens when that threshold is reached.

🧪 Lab Steps

  1. Inspect /stats to discover the current rate-limit configuration.
  2. Run the controlled simulator.
  3. Observe when requests begin receiving HTTP 429.
  4. Wait for old requests to leave the tracking window.
  5. Make another local request and observe the result.

🧪 Commands

curl http://127.0.0.1:5000/stats
python traffic_sim.py
curl -i http://127.0.0.1:5000/

⚠️ Controlled Lab

All testing must remain against the local FloodGate training service at 127.0.0.1. Do not modify the simulator to target external systems.

🧠 Think Like a Defender

A rate limiter is usually time-based. Reaching a threshold does not necessarily mean an IP has been permanently banned.
