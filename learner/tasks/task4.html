🕵️ Task 4 — Detection

Learning Objectives

Detection is about recognizing suspicious patterns in available security telemetry. Instead of simply identifying endpoints, examine the behavior recorded in FloodGate's logs.

🧪 Lab Steps

  1. Run the controlled simulator if necessary.
  2. Open /logs and examine multiple events.
  3. Look for repeated source addresses.
  4. Compare ALLOWED and BLOCKED events.
  5. Pay attention to the order in which events occur.
  6. Look for a change from normal responses to rejected requests.

🧪 Commands

curl http://127.0.0.1:5000/logs
curl http://127.0.0.1:5000/stats

⚠️ Controlled Lab

All testing must remain against the local FloodGate training service at 127.0.0.1. Do not modify the simulator to target external systems.

🧠 Think Like a Defender

A single event has limited context. Repeated events, timing, source information, and response changes provide stronger detection evidence.
