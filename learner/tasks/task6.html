🚨 Task 6 — Investigation

Learning Objectives

You are now acting as a junior security analyst. A monitoring alert indicates unusual HTTP activity. Your job is to reconstruct what happened by correlating several pieces of evidence rather than relying on one source.

🧪 Lab Steps

  1. Run the controlled simulation.
  2. Record the totals shown by /stats.
  3. Examine the individual events in /logs.
  4. Compare the source addresses and event statuses.
  5. Compare the HTTP responses from the simulator with the log evidence.
  6. Construct a timeline of the incident.

🧪 Commands

python traffic_sim.py
curl http://127.0.0.1:5000/stats
curl http://127.0.0.1:5000/logs

⚠️ Controlled Lab

All testing must remain against the local FloodGate training service at 127.0.0.1. Do not modify the simulator to target external systems.

Questions

Question 1

How many requests were generated by the standard controlled simulation?

Question 2

How many of those requests received normal successful responses?

Question 3

How many requests were rejected?

Question 4

Which request number marks the transition into rejected requests?

Question 5

Did the rejected requests originate from the same controlled source as the accepted requests?

Question 6

What evidence shows that the service's defensive control was triggered?

Question 7

What is the most likely explanation for the incident?

🧠 Think Like a Defender

An incident explanation should be supported by multiple independent observations: volume, responses, source information, and logs.
